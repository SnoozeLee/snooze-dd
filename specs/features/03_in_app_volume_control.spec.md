## 1. 🎯 概述与业务目标 (Overview & Objectives)

### 1.1 背景与痛点
用户在使用 SnoozeDD 专注、学习或冥想时，常常同时在播放音乐、白噪音播客或进行在线语音会议。如果提醒音量只能跟随手机系统媒体音量调节，就会出现“调高系统音量导致背景音乐震耳欲聋，调低系统音量又导致弱提醒听不清楚”的矛盾。用户需要应用内具备独立于系统全局音量的自定义调节能力。

### 1.2 核心目标 (Goals)
- [ ] 提供纯应用内的 5 级离散音量梯度（1~5 级），与系统全局音量解耦。
- [ ] 调节应用内音量时，精准控制伴随提示音 (Chime) 与文本朗读 (TTS) 的内部增益。
- [ ] 提供即时音量试听与本地持久化，切换后立即生效并记录用户偏好。

### 1.3 非目标 (Non-Goals)
- 本次不改动手机操作系统本身的全局媒体音量（Android AudioManager / iOS AVAudioSession outputVolume）。
- 不支持连续浮点滑块输入（统一规范为直观清晰的 5 个固定挡位）。

## 2. 🚧 需求范围与边界 (Scope Boundaries)

### 2.1 包含范围 (In-Scope)
1. **5 级音量挡位定义**：
   - 1 级（20% / 0.20）：极轻柔，适合佩戴入耳式耳机或深度冥想环境。
   - 2 级（40% / 0.40）：柔和，适合安静书房或夜间小憩。
   - 3 级（60% / 0.60）：适中，标准伴随音量。
   - 4 级（80% / 0.80，默认）：清晰，适合日常专注伴听。
   - 5 级（100% / 1.00）：饱满，适合外放且有环境噪音场景。
2. **UI 交互入口与展示**：
   - 主界面 AppBar 显式提供音量调节入口图标（随当前挡位动态变化图标形态）。
   - 弹出轻量快捷弹窗，展示 5 档分段器（SegmentedButton / Slider）与对应挡位文字说明。
   - 弹窗内配备「试听当前音量」按钮，切换挡位可立即试听伴随音与 TTS。
3. **播放通道联动**：
   - `AudioChimeService` 与 `TtsService` 播放时统一使用所选挡位对应的音量系数。
   - 配置通过 `StorageService` 本地持久化，下次启动自动恢复。

### 2.2 不包含范围 (Out-of-Scope)
- 不覆盖第三方媒体 App（如 Spotify / 网易云音乐）的播放行为。
- 不提供针对左右声道独立的平衡调节。

## 3. 👥 用户角色与场景用例 (User Stories)

| 角色 | 期望操作 | 达成价值 |
| :--- | :--- | :--- |
| 音乐专注者 | 正在戴耳机听轻音乐，将 SnoozeDD 应用内音量设为 1 级 (20%) | 提示音柔和不惊扰，不打断耳机内的音乐心流 |
| 办公室用户 | 使用手机外放计时，将应用内音量设为 4 级 (80%) | 即使离手机一段距离也能清晰接收语音弱提醒 |
| 冥想小憩者 | 在设置面板切换 2 级并点击试听 | 立即确认声音大小是否符合当前安静环境预期 |

## 4. 🗄 数据结构与状态契约 (Data Contracts)

```typescript
// 音量等级枚举与系数映射
export enum VolumeLevel {
  level1 = 1, // 0.20
  level2 = 2, // 0.40
  level3 = 3, // 0.60
  level4 = 4, // 0.80 (Default)
  level5 = 5, // 1.00
}

// 辅助转换工具
export function volumeLevelToScalar(level: VolumeLevel): number {
  return level * 0.2;
}

export function scalarToVolumeLevel(scalar: number): VolumeLevel {
  const clamped = Math.min(1.0, Math.max(0.2, scalar));
  const level = Math.round(clamped / 0.2);
  return level as VolumeLevel;
}
```

## 5. 📋 业务规则 (Business Rules)

1. **解耦性保证**：绝对不调用修改系统全局硬件音量的底层 API。
2. **持久化与默认值**：首次进入默认 4 级 (0.80)，修改后立即写入本地存储 `TimerSession.volume`。
3. **即时试听防重叠**：在音量弹窗内点击「试听」时，若已有试听正在发声，先停止上一段再开始新挡位试听。

## 6. ✅ 验收标准 (Acceptance Criteria)

- [ ] **场景 1：5 档切换与系数转换**
  - **When**：在音量面板选择 2 级 (40%)
  - **Then**：`TimerSession.volume` 变为 `0.4`，保存至持久化。
- [ ] **场景 2：音量试听反馈**
  - **When**：在弹窗内切换到 1 级并点击试听
  - **Then**：听到以 20% 增益播放的提示铃音与测试语音。
- [ ] **场景 3：计时运行时音量生效**
  - **Given**：用户将应用内音量设为 5 级 (100%)
  - **When**：倒计时触发 Checkpoint 播报
  - **Then**：TTS 与提示音以 1.0 满格音量播放。
