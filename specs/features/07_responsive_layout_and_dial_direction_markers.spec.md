## 1. 🎯 需求背景与问题定义

根据实际设备使用体验与多屏适配反馈，解决以下 4 项核心视觉与交互问题：

1. **窄屏下自定义按钮不可见**：
   - 当前「自定义...」放置在横向滚动条最右侧末尾，窄屏（如 360px~375px）下一屏无法显示，需要向右滑动才能发现。
   - **决议**：将「自定义...」移至最左侧首位常驻，右侧跟随各个标准分钟预设药丸。
2. **宽屏下底部操作按钮撕裂分离**：
   - 桌面端或横屏全屏时，`spaceEvenly` 导致重置按钮在最左端、节点详情在最右端，操作距离过大。
   - **决议**：为底部操作控制栏增加最大宽度约束（`maxWidth: 380px`）并保持居中，按钮间距保持 24px 黄金舒适区。
3. **表面微质感过浅**：
   - 高分屏下微粒过细弱，无法形成物理纸张/砂石触感。
   - **决议**：颗粒半径提升至 1.0px~1.6px，不透明度提升至 8%~12%（暗色 10%~14%），严格保持零渐变。
4. **表盘刻度缺乏正向与倒计的直观区分**：
   - 当前圆环上只显示 `5m`、`10m`，无法直观分辨是“已进行至 5m”还是“剩余 5m”。
   - **决议**：采用方向性微图标与标牌区分：
     - 正计时节点（`elapsed`）：带有向右流逝指示微图标（流逝箭头/前进符），标牌显示 `▶ 5m`。
     - 倒计时节点（`remaining`）：带有倒计时指示微图标（倒数沙漏符），标牌显示 `⏳ 5m`。
     - 纯矢量/高精排版绘制，严禁系统原生大 Emoji。

## 2. 🧱 技术契约与实现方案

### 2.1 表盘标记计算扩展 (`lib/ui/widgets/timer_dial.dart`)
`DialMarkerInfo` 补充 `isElapsed` 属性或直接在 `label` 中生成带前缀图标：
- `remaining`: `'⏳ $mins$secsStr'`
- `elapsed`: `'▶ $mins$secsStr'`

### 2.2 预设栏首置自定义 (`lib/ui/screens/timer_screen.dart`)
在 Row 的最前列放置 `ActionChip`（自定义...），随后渲染 `standardPresets`。如果当前选中了非标准自定义分钟数，紧随其后高亮显示当前自定义分钟。

### 2.3 底部栏宽度约束 (`lib/ui/screens/timer_screen.dart`)
包裹 `Center(child: ConstrainedBox(constraints: BoxConstraints(maxWidth: 380), child: ...))`。

### 2.4 微质感参数调优 (`lib/ui/widgets/texture_background.dart`)
- `dots`: `dotAlpha` 调至 `0.10` (Light) / `0.13` (Dark)，点半径调至 `1.05px`。
- `grain`: `baseAlpha` 调至 `0.085` (Light) / `0.11` (Dark)，噪点半径放大至 `0.9 ~ 1.7px`。
