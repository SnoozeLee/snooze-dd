## 1. 🔍 核心问题诊断与重构目标

根据用户明确提出的 4 大体验痛点，执行针对性系统重构：

| 用户反馈痛点 | 根本原因分析 | v2.0 重构方案 |
| :--- | :--- | :--- |
| **背景缺乏纹理** | 纯单色平涂导致数字界面冰冷单薄，缺乏物理实体质感 | **引入高级哑光砂石/和纸微噪点纹理 (Matte Grain Texture)**，纯色基底上叠加微透明微粒（无渐变），呈现高端实体腕表/高档手工纸张般的触摸感。 |
| **对比度低、容易看不清** | 之前为了追求温和，部分文字和副色过浅（低于 4.5:1） | **全线升级为 WCAG AAA 级高对比度（> 10:1 至 16:1）**。亮色文字直接沉至浓郁深炭墨；暗色文字提至高纯度象牙白，圆环轨道轮廓加深分明。 |
| **字体不够粗** | 原先使用了 `FontWeight.w300` 极细体，远距离或弱光下一片模糊 | **计时数字全面升级为 `FontWeight.w700 ~ w800` 粗体**，笔画饱满笃定，即使手机平放桌面 1 米外也能一眼看清剩余时间。 |
| **不够圆润** | 原先部分圆角较小，线条偏生硬 | **全面采用 Squircle 超大圆角（24px~32px）与全圆胶囊形态**，表盘刻度线末端全部使用 `Round Cap`，视觉温润可亲。 |

## 2. 🧱 物理材质感设计：纯色 + 微质感纹理（无渐变）

在保持 **“坚决不使用颜色渐变”** 的前提下，如何制造高级感？
答案是**微物理表面（Micro-Texture Surface）**：
1. **触感微噪点（Fine Noise Grain）**：
   - 亮色模式下模拟 **Arches 水彩纸 / 日本和纸 (Washi)** 的自然纤维哑光感。
   - 暗色模式下模拟 **磨砂火山玄武岩 / 铸铝表面 (Sand-cast Basalt/Metal)** 的沉稳哑光感。
2. **结构点阵（Precision Stippling Dots）**：
   - 备用方案：采用 0.5px 精细几何点阵，模拟顶级德国音响（如 Braun / Teenage Engineering）的精密打孔面板。

## 4. 🔤 字体与几何圆润度规范

1. **字体加粗 (Typography)**：
   - 倒计时主秒数：`font-weight: 700 (Bold)`，采用等宽对齐数字（Tabular Numbers），笔画粗厚有力。
   - 节点时间刻度（如 `5m`、`10m`）：`font-weight: 700`，字号由 9px 放大至 11px，彻底解决小字看不清问题。
2. **几何圆润 (Rounded Shapes)**：
   - 表盘进度弧线：`stroke-linecap: round`，圆润饱满的起止端点。
   - 节点标记：6px 饱满小圆圈 + 2px 独立描边隔离环。
   - 所有卡片容器：统一使用 `24px` 超大圆角。
   - 所有操作按钮：统一使用 `9999px (rounded-full)` 极圆胶囊。
3. **严禁使用 Unicode Emoji 符号作为操作图标 (Strict Vector Icons Only)**：
   - 绝对禁止在按钮、状态条、顶栏等交互区域使用系统 Unicode 字符（如 ⏸、↺、⚙、🔊、🔔 等 Emoji/符号，其在各平台上粗细不均、色度混乱且极度廉价）。
   - 一律统一使用精细矢量几何路径（Flutter `Icons.xxx` 与高保真 SVG Vector），具备统一的 1.5px~2.0px 线宽与圆润拐角，维持纯粹的工业级现代美感。

## 5. 🏗️ 系统架构与状态持久化设计

1. **配色方案枚举 (`AppPalette`)**：
   - `warmUmber` (岩茶金石)
   - `pineSlate` (松烟墨青)
2. **主题模式 (`ThemeMode`)**：
   - `system` (跟随系统)
   - `light` (明亮和纸)
   - `dark` (沉稳曜石)
3. **纹理类型 (`TextureStyle`)**：
   - `grain` (哑光砂石/和纸微噪点)
   - `dots` (精密几何打孔点阵)
   - `none` (纯净无噪点)
4. **状态持久化**：
   - 在 `StorageService` 中记录 `theme_palette`、`theme_mode` 与 `theme_texture`，支持应用冷启动恢复。
5. **主题提供者与切换组件**：
   - `ThemeController` (ChangeNotifier) 统一分发状态。
   - `ThemeSettingDialog` 提供可视化配色与主题切换面板。
   - `TextureBackground` 作为顶层或 Scaffold 包装层，用轻量级 `CustomPainter` 高效绘制微质感，无外部图片依赖，严格 0 渐变。
